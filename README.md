# VectorMágico

App Android que convierte una imagen (JPG, PNG…) en vector de forma automática y la deja lista para DTF:
quita el fondo, vectoriza a color y exporta SVG, PDF o PNG transparente a 300 dpi.

## Cómo obtener el APK
1. Crea un repositorio en GitHub y sube todo el contenido de esta carpeta (incluida `.github`).
2. En la pestaña **Actions** se compila solo. Tarda unos 3–5 minutos.
3. Descarga `VectorMagico.apk` desde **Releases** (o desde el artefacto de la ejecución) e instálalo.

Requiere Android 10 o superior. Los archivos se guardan en `Descargas/VectorMagico`.
